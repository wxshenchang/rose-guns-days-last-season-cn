## 重要裁决

- 地名 スモールロックチャイナタウン 沿用 1.5 的「小石唐人街」。同一地区的日文「小岩」写法按原文保留。ファーザー・ケイレブ 统一为「凯雷布教父」，对应第二季酒名的双关。グランドボス 正式头衔用「总首领」，按人物关系保留「大当家」等自然口语。
- 第二季酱油价格在不同原文段落有每升与每瓶的差异，按原文保留各处金额和单位。L131061 的日期与「约两个月」也有出入，译文照录，详见分段记录。
- 第二季结尾提及开场曲时，L160608 恢复音乐人署名「ラック眼力」。[07th Expansion 原声带介绍](https://07th-expansion.net/2012summer.htm)
- 第四季 L235883 的原文将荷官明牌写为 A，同场 L235734 与 L236049 均明确为方片 Q。合稿用方片 Q。L253017 原文把珍妮的交谈对象写成珍妮夫人，依据该段主语及后日谈的交接说明改为罗斯夫人。两处都在修订清单留下依据。
- 祐司是斯特拉亡妹的孩子，由斯特拉和理查德照顾。第三季去掉了误称斯特拉为生母的解释，保留场景里人物按自身认知使用的称谓。
